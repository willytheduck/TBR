# TBR (TEXT BASED RPG)
Hello, This is my third game I've created so far

This is basically a terminal rpg games but is inspired by undertale (toby fox). The difference is that I made Papyrus as the last boss instead of asgore or sans. This is a fun project to do since I can make some story my own with some inspiration from the undertale lore. This game has gym also cuz why not adding it. (fun fact: I nerfed the boss 10 times by now)

How to run:
1. Download the Releases (should be in .exe)
2. Run it
3. You can type in there and Enjoy!

How to play:
1. Type your name
2. Choose the difficulty (I recommend normal)
3. Press Enter to continue
4. The dodging uses wasd (w = ^, a = <, s = v, d = >)
5. There is 3 Ending so GoodLuck!
